# Publication privacy scope

[Guide index](README.md)

This repository was written from a curated set of technical findings and verified results. Raw investigation directories were not imported.

The publication excludes:

- Operator names, personal email addresses, local usernames, hostnames and workstation paths.
- Actual network addresses, hardware MAC addresses, device serials and boot/session identifiers.
- Account information, credentials, tokens, cookies and authenticated request headers.
- Private signing-key material, vendor request-signing constants and signed download URLs.
- Raw RAM captures, partition images, firmware, APKs, compiled helpers, screenshots and unfiltered logs.
- Private memory-system identifiers and local provenance records.

The retained model/build identifiers, generic Android UID values, static kernel profile and upstream project links describe the technique. Professional names and public handles in the credits are intentional attribution to the sources of the work. `<PROJECTOR_IP>` and stock-image hash placeholders must be substituted locally.

The guide's evidence consists of distilled verification results. It does not claim that confidential raw artifacts are available to public readers. Working files and all Git blobs selected for publication were scanned before the initial push.
